# 🤖 Portafolio Profesional - Ingeniería Mecatrónica

## Integrantes
- Esteban Zambrano

## Descripción
Portafolio web desarrollado con Bootstrap 5 como proyecto académico.
Incluye diseño responsivo, animaciones, validación de formulario y
estructura moderna enfocada en Ingeniería Mecatrónica.

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome

## Características
- Sistema Grid de Bootstrap
- Diseño adaptable (mobile, tablet, desktop)
- Animaciones y efectos hover
- Scroll suave
- Validación de formulario
- Código organizado y semántico

## Objetivo Académico
Aplicar los conocimientos adquiridos en desarrollo web
para crear una página profesional moderna y funcional.
